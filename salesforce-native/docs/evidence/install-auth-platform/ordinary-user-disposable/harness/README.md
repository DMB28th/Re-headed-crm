# Ordinary-user measurement and receipt harness

Run `node --test salesforce-native/docs/evidence/install-auth-platform/ordinary-user-disposable/harness/*.test.cjs` from the repo root. Tests inject synthetic HTTP responses; no live request occurs. `measure(input, fetcher)` is a controller-callable verifier skeleton with no default fetch, CLI, file reads, mutation, token acquisition, deployment or credential provisioning. It requires private independently controller-approved exact instance/login/identity origins and Site origin/path before transport, plus full checksum18 expected actor/org; measures identity, authenticated global describe and exact probe schema; returns sanitized booleans/status only. The explicitly injected live transport, private input assembly, approval checks and measurement sequencing belong to the controller. `validate(receipt)` assesses the accumulated private summary as described in ../REVIEW.md. Each receipt step carries its exact measurement object; identity/actor/schema flags are mandatory, and CRUD is derived solely from the validated Use measurement. Same retained token is required for the matrix and valid->revoked lifecycle; unknown/nested and guest/fabricated run before revocation. Guest/fabricated requests have separate positive controls; revoked mode records post-revocation REST401. Store private input in ignored private paths; never replace synthetic fixture constants with live values. No validator result alone counts as live proof.
