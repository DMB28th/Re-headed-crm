Same-org unrelated api acceptance is consistent with this model, subject to future Cardstack permissions.

Current implementation decision: this evidence supports proceeding under the bounded Salesforce org/API authorization model; an exact current-app accessor or per-client route audience is not a prerequisite under that model.
